# 狐狸奖励关键帧动画

训练页右侧由 `FoxReward.jsx` 挂载，Canvas 的逐帧绘制、图片预加载和事件订阅在 `foxAnimation.js`。当前资产实际文件名为 `src/assets/fox-spirites.png`，沿用用户文件名；真实尺寸 1086×1448，按 4 列×4 行读取。

- 从左到右、从上到下编号 1–16；代码内部编号 0–15。
- 待机 1–4 帧，每帧 250ms，1 秒一轮。
- 监听现有 `EVENTS.REP_COMPLETED`，庆祝 5–16 帧，每帧 140ms，共 1.68 秒，然后恢复待机。
- 图片加载完成前不播放也不排队事件；庆祝期间忽略重复触发。
- 使用 requestAnimationFrame 的单调时间计算帧号，低帧率时跳过过期帧，不累积定时器。
- 按实际图片尺寸算出每格（271.5×362），保留小数并内缩至少 1px，再居中裁为 3:4，避免相邻帧露边。窗口保持 3:4，适应页面宽度和设备像素比。
- 卸载取消动画循环和事件订阅。图片失败只显示提示，不影响训练。

这套属于关键帧动画。原图帧间背景和造型存在轻微差异，可能抖动，适合验证游戏效果，不能直接达到流畅 3D 视频程度。没有将 16 帧拉长到 15 秒。

`npm run dev` 后打开正式首页，进入 Training 可见右侧狐狸。真实深蹲由原有识别与计数模块产生事件，本次没有修改其逻辑。离线上传分析若快速连续产生多次事件，同样只播放一段庆祝，不排队；训练页结束卸载时动画停止。

独立验证入口：`/src/story/debug.html`。按钮发出模拟事件，不开摄像头、不保存训练数据，方便检查庆祝和待机切换；该页面仅供开发，不包含在默认生产入口中。

测试：`node --test tests/foxAnimation.test.js`，覆盖时序、忽略重复事件、真实尺寸裁剪、预加载、失败和卸载清理。构建：`npm run build`；代码检查：`npm run lint`。
